# Wayfinder app

An app to help me and other employees at Migrationsverket to find our way to meeting rooms. [Try it out here](https://philiphekstromer.github.io/wayfinder)

## 🗺️ About the app

This is a simple app I made to help me find my way to our meeing rooms. I'm not in the office that much and I always get lost. Maybe it can help someone else too!

### ⛏️ Built With

React, [Midas design system](https://designsystem.migrationsverket.se/) and Github Copilot
